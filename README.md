# pdt-ces

Metadata for the [Cooperative Election Study (CES)](https://dataverse.harvard.edu/dataverse/cces), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** started from the PublicDataToolkit template; no records yet.

## What the dataset is

A large online survey of U.S. adults about elections and politics, run by YouGov since 2006 (as the CCES until 2020), with a common-content file per year and a cumulative file that harmonizes the years.

## Terms of use

The terms are at https://creativecommons.org/publicdomain/zero/1.0/. They haven't been reviewed yet, so nothing built from this repo may ship (STANDARD.md §8). Once a person has decided them, summarize them here; the decision is in [`dataset.yaml`](dataset.yaml).

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum.

## How to use the metadata

- `metadata/releases/<release>/variables.jsonl`: one record per variable, with where each fact came from.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

How to cite the dataset (from the publisher) and this repo.

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build
make views
make check
```
